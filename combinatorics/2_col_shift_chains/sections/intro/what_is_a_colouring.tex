The switch set \(S_c(\vec{e})\) of  \(\vec{e}\) in \(c\) is the set of switches contained in \(\vec{e}\). 
\pause 

\(|S_C(\vec{e})|\) is the switch count of \(\vec{e}\)
\pause

  \begin{itemize}
    \item<1-> A switch \(x\) has position \((i,i+1)\) in \(\vec e\) if
      \(e_i<x<e_{i+1}\), for \(i=1,2,3\).
    \item<2-> An edge with exactly two switches, both at that position,
      is a \((i,i+1)\)-edge: \((1,2)\), \((2,3)\), or \((3,4)\).
    \item<3-> An edge is monochromatic iff every gap has an even number
      of switches.
  \end{itemize}
